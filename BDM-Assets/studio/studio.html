먼저 스타일을 하나 만들어주세요

Step 00 · Setup

Studio는 스타일 레퍼런스를 기반으로 캐러셀을 만듭니다. 따라하고 싶은 인스타 캐러셀의 게시물 URL을 넣거나 직접 스크린샷을 올리면, Claude Vision이 톤·구조·색감을 분석해서 생성 엔진에 자동으로 주입합니다.

지금은 토큰 제한이 있어서 한두 개 스타일만 등록·분석해두고 쓰시길 권장합니다.

💡 Step 1 입력 후 🚀 생성 시작 을 누르면 Step 2~4 가 같은 화면에 펼쳐지면서 텍스트·이미지·완료를 자유롭게 오갈 수 있습니다.

BDM Lab Studio 에 오신 걸 환영합니다

        
아이디어 한 줄 또는 트렌드 한 개로, SNS 콘텐츠 초안을 빠르게 만들어보세요.

      

      
    

    

      

        세 채널 (📸 Carousel · 📝 Blog · 🧵 Threads) 의 초안을 만들어주는 도구입니다.
        제일 강력한 무기는 '집단지성' 이에요. 여러분이 콘텐츠를 만들고, 수정하고, 피드백 한 줄을 남기는 그 모든 행동이 모여 시스템이 어제보다 오늘 더 똑똑해집니다.
      


      
시작은 두 갈래

      
    
        
  1. 내 아이디어로 — 다루고 싶은 주제를 적으면 알아서 초안으로 풀어줍니다.
    2. 
        
  2. 트렌드로 — 📡 Pulse 에서 시스템이 포착한 신선한 신호를 골라, 남보다 한발 빠르게 내 콘텐츠로.
    3. 
      


      
🧬 집단지성이 작동하는 방식

      

        

          

            
여러분의 행동이 데이터가 됩니다

            
    
              
  • 텍스트 직접 수정 (어떻게 고쳤나)
    • 
              
  • 재생성 시 한 줄 피드백
    • 
              
  • 슬라이드별 💬 인라인 의견
    • 
              
  • Pulse 의 Pin / Keep / Skip 판정
    • 
              
  • 완료 시 별점·테마 태그·자유 응답
    • 
            

          

          

            
데이터가 룰로, 룰이 진화로

            
    
              
  • 모든 행동이 DB 자동 누적
    • 
              
  • 관리자가 주기적으로 패턴 검토
    • 
              
  • 반복되는 패턴 → 새 룰 추출
    • 
              
  • 새 엔진 버전으로 승격
    • 
              
  • 다음 호출부터 모든 사용자에게 즉시 적용
    • 
            

          

        

        

          예시: 이번 주 5명이 "데이터 출처가 모호하다" 라고 피드백을 남기면 → 다음 버전에 "수치 인용 시 출처 명시 강제" 룰이 자동 추가되어 → 모든 사용자에게 즉시 반영됩니다.
        

      


      
3가지 채널

      
    
        
  1. 📸 Carousel — 인스타 캐러셀 (분량은 입력 단계에서 5~12장 자유 선택). 텍스트 + 이미지 시각화 중심.
    2. 
        
  2. 📝 Blog — 네이버 블로그 장문. SEO 최적화 + 무료 사진 자동 첨부.
    3. 
        
  3. 🧵 Threads — 짧은 호흡, 한 주제를 3가지 톤으로 동시 생성.
    4. 
      


      
잘 쓰는 비결 3가지

      
    
        
  • 스타일 분석을 먼저. 🎨 스타일 라이브러리 에서 채널별로 1~2개의 레퍼런스를 등록하고 🤖 분석하기 까지 끝내두면 톤이 잘 맞는 결과가 나옵니다.
    • 
        
  • 한 줄 피드백이 전부를 바꿉니다. "말투가 어색", "결론이 약함" 같은 사소한 의견도 전체 사용자 데이터에 합쳐져 다음 버전의 룰이 됩니다.
    • 
        
  • 막히면 상단 💬 개선사항 또는 ❓ FAQ 를 봐주세요.
    •
